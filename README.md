# MA376 Data

Every dataset used by MA376, Applied Statistics, at the United States Military Academy.
Nothing here needs an account. Clone it, or read any file straight over the web.

```r
base <- "https://raw.githubusercontent.com/defense031/ma376-data/main/"

# a capstone dataset
concrete <- read.csv(paste0(base, "project_data/concrete-strength/concrete_strength_enriched.csv"))

# a textbook dataset (see the note on na.strings below)
seaweed <- read.csv(paste0(base, "package_data/sleuth3/case1301.csv"), na.strings = "")
```

## What is here

| folder | what it holds |
|---|---|
| `project_data/` | 20 datasets for the semester capstone. Each folder has one csv and a `DICTIONARY.md` giving the provenance, a column dictionary, and how the file was assembled where more than one source was merged. All real, all publicly sourced. |
| `package_data/` | 193 textbook datasets exported to csv: `sleuth3/` (174), `islr2/` (18), `base/` (1). For readers who are not working in R. In R, install the packages instead. |
| `manifest.csv` | Every file in the repository with its source, path, rows, columns, and size. |
| `ATTRIBUTION.md` | Where each mirrored dataset came from and under what license. |

## If you are working in R

The textbook data are better taken from the packages themselves, which is one line:

```r
install.packages(c("Sleuth3", "ISLR2"))
library(Sleuth3); library(ISLR2)
data(case1301)
```

`Sleuth3` holds the data for Ramsey and Schafer, *The Statistical Sleuth* (3rd ed.).
`ISLR2` holds the data for James, Witten, Hastie and Tibshirani, *An Introduction to
Statistical Learning* (2nd ed.). `USArrests`, which ISLR's chapter-12 lab uses, is in
base R's `datasets` and needs no package at all.

## Reading package_data back

In `package_data/` an **empty field means missing**, so read those files with
`read.csv(path, na.strings = "")`.

R would otherwise write missing values as the token `NA`, which is indistinguishable
from a real value in `Sleuth3::ex0918`, where the factor level `"NA"` means North
America. One cost of the convention: `ex0721` holds a single genuinely empty `Name`
that reads back as missing.

Files under `project_data/` are byte-for-byte copies of the shipped csv files and use
R's ordinary conventions. Read those with a plain `read.csv(path)`.

## Taking the whole capstone library at once

```r
sets <- read.csv(paste0(base, "manifest.csv"))
sets <- sets[sets$source == "project", ]
dir.create("ma376-data", showWarnings = FALSE)

for (i in seq_len(nrow(sets))) {
  download.file(paste0(base, sets$path[i]),
                file.path("ma376-data", basename(sets$path[i])))
}
```

One file is large enough to be slow over the web: `online-retail` is 48 MB. Download that
one once and read it from disk.

## Licenses

The mirrored textbook data are GPL, and `LICENSE-GPL-2` plus `ATTRIBUTION.md` carry the
license text and the attribution each package requires. The capstone datasets are drawn
from public sources named individually in each folder's `DICTIONARY.md`.
