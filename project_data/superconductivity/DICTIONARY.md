# Superconductivity

2,500 superconductors described by 81 features engineered from chemical formulas, with critical temperature as the response.

**File.** `superconductivity_enriched.csv` (2,500 rows x 169 columns, assembled from the sources below)

## Provenance
- Base data: UCI Machine Learning Repository (Hamidieh), retrieved 12 Jul 2026. (https://archive.ics.uci.edu/dataset/464/superconductivty+data)
- Merged in: UCI superconductivity archive, unique_m.csv (chemical-composition companion file) (https://archive.ics.uci.edu/dataset/464/superconductivty+data)

## How the file was assembled
The base dataset was extended with the following merges. The base columns are unchanged;
every merged column is attributed in the table above.

1. **UCI superconductivity archive, unique_m.csv (chemical-composition companion file)** — row-aligned to the full 21,263-row train.csv (alignment verified exactly on all 81 features and critical_temp), then carried through this kit's 2,500-row subsample; adds 86 element-fraction columns and the material formula. Adds: `H`, `He`, `Li`, `Be`, `B`, `C`, `N`, `O`, `F`, `Ne` and 77 more.
